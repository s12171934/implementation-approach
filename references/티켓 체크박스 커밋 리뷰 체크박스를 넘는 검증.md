# 티켓 체크박스 커밋 리뷰 체크박스를 넘는 검증

> [[티켓 체크박스 커밋 리뷰 루프]]에 얹는 티켓 단위 검증 세 가지다. 체크박스 리뷰는 커밋 하나의 스테이지만 보므로, 여러 커밋에 걸친 구조·저장소 사이 계약·실제 화면은 그 밖에 있다.
> 이 층이 없으면 티켓이 모두 verified 여도 기능을 쓸 수 없는 상태가 마지막 통합 단계에서야 드러난다.

## 1. 소비자 착수 실서버 대조

- **대상** — 다른 저장소 티켓(생산자)이 만든 서버 계약을 소비하는 티켓.
- **시점** — 착수 직후, 첫 구현 체크박스 전.
- **방법** — 생산자의 verified 헤드를 격리 스택으로 띄우고, 이 티켓이 소비할 API 가 설계대로 응답하는지 실제 요청으로 확인한다. 생산자 테스트가 그린이라는 사실로 갈음하지 않는다.
- 커밋을 만들지 않고 코드를 고치지 않는다. 결과는 볼트 기록으로 남긴다.
- 생산자가 아직 verified 가 아니면 선행 대기다.
- **불일치면 그 티켓만 「계약 불일치」로 멈추고** 상위 코디네이터에 올린다. 소비자 쪽에서 계약을 맞춰 발명하지 않는다.
- 격리 스택은 E2E 스택·다른 티켓의 스택과 포트·DB 를 나눠 쓴다.

## 2. UI 티켓 verify 의 화면 한 장면

- **대상** — 화면을 만든 티켓의 verify 체크박스.
- **방법** — 측정(완료 기준 테스트, TypeScript 저장소는 타입 검사)에 더해 **화면 한 장면을 디자인 스냅숏과 대조**한다.
  - 공용 UI 라이브러리 티켓은 Storybook 을, 앱 티켓은 격리 스택의 실화면(시드 계정)을 대조한다.
  - 결과표 첫 줄은 `판정: 일치` 또는 `판정: 불일치`, 그 아래 화면 · 프레임 · 캡처 경로 · 차이.
- 디자인 스냅숏이 없으면 사람 게이트로 멈춘다. 무인 세션이 디자인 도구를 직접 조회하지 않는다.
- **불일치면 verify 앞에 수정 체크박스를 더하고**(지라 체크리스트에도 더한다) 그 커밋 뒤 verify 를 다시 돈다.
- 고치지 않을 불일치(시안끼리의 모순 등)는 **사람 판정으로만 수용한다.** 수용 사유와 시각을 기록하고 커밋 본문에 남긴다. 에이전트가 스스로 수용하지 않는다.

## 3. 티켓 통합 리뷰

- **시점** — 마지막 체크박스 커밋 뒤, 티켓 완료 처리 전.
- **대상** — 체인 앞 브랜치(없으면 베이스) 대비 브랜치 전체 diff 와 커밋 목록.
- **리뷰어** — 체크박스 리뷰와 같은 교차 구성, 새 세션, 1 라운드. 코드를 고치지 않고 커밋하지 않는다.
- **관점** — 체크박스 리뷰가 볼 수 없던 것만 본다.
  - 같은 상태·판정의 정본이 여러 곳에 생겼는지, 같은 동작의 경로가 둘 이상인데 일부만 처리됐는지.
  - 커밋 사이 계약(타입 · 필수 prop · 직렬화 필드 · 에러 코드)의 어긋남.
  - 비기능 상한(입력 크기 · 소요 시간 · 락 안 작업), 설계 범위 밖 경로로 새는 변화.
  - 테스트가 단언하지 않는 동작, 체크박스 문구와 다른 구현.
- **지적 0 이면** 완료 처리로 간다.
- **지적이 있으면 티켓 끝에 수정 체크박스 하나를 더하고**(지라 체크리스트 포함) 루프대로 처리한다.
  - 판정은 그 수정 체크박스의 구현 세션이 한다 — 원래 코드를 쓴 세션들은 이미 닫혔으므로 「판정 주체는 그 코드를 쓴 세션」의 예외다.
- 수정 커밋 뒤 완료 기준 테스트와 타입 검사를 다시 돌리고 측정만 기록한다. 추가 커밋은 만들지 않는다.
- 재개된 티켓의 통합 리뷰는 재개 뒤 커밋만 대상으로 하되, 그 커밋이 바꾼 공용 컴포넌트의 다른 소비처 영향은 본다.

## 금지

- **생산자 테스트 그린을 실서버 대조로 갈음하는 것.**
- **화면 불일치를 에이전트 판단으로 수용하는 것.**
- **통합 리뷰 지적을 기존 체크박스 커밋에 섞어 넣는 것** — 수정 체크박스로 더한다.

## 완료 판정

- 소비자 티켓 — 실서버 대조 결과 「일치」가 볼트 기록에 있다.
- UI 티켓 — verify 커밋에 화면 대조 「일치」 또는 사람 수용 기록이 있다.
- 모든 티켓 — 통합 리뷰 지적 0, 또는 수정 체크박스 커밋과 재검증 통과.
